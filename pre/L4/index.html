Part 1 讲的是一个具体合作过程：我们如何从 substantive puzzle 走到理论、设计、分析、批评和修正。Part 2 要把这个经验抬高一个层次。我们不再问 agent 帮我们完成了什么，而是问：什么样的组织安排，使这种合作成为可能？以及，这个安排是否改变了科学知识的生产方式。

PART 1 · A CONCRETE CASE
Starting point

A substantive puzzle, not a model.

Working question

How does the agent change the next research move?

FIRST, WATCH THE COLLABORATION HAPPEN

We begin with one research question,
not with AI capability.

PUZZLEWhy do similar organizations produce different citizen outcomes?
DATAOne outcome, several organizational and contextual variables.
DECISIONWhat should we learn before choosing a model?
Agent’s first job: make the question more discriminating, not more impressive.

前半段先不要讲 epistemic labor。先让学生看到一个实际研究。我们从一个社会科学 puzzle 开始：为什么相似的组织环境下，不同组织会产生不同的 citizen outcomes？我不会一开始告诉 agent 跑什么模型，而是让它先追问 outcome、unit of analysis、时间范围和可能机制。agent 的第一个任务不是生成漂亮的 research question，而是把问题变得 more discriminating。

实际合作不是一个大 prompt：“请帮我做研究”。我们把它拆成一串小的、可以检查的 moves。先澄清 outcome，再提出 mechanism，再把 mechanism operationalize 成变量，然后做分析，最后判断 claim。每一步 agent 都可以给方案，但研究者要明确接受、拒绝或重新定义什么。学生可以把这张图当作和 agent 合作 conduct research 的最小工作框架。

WORKING PROMPT
Bad prompt

“Run machine learning and explain the result.”

Better prompt

Declare the question, evidence, and failure checks first.

THE AGENT NEEDS A RESEARCH CONTRACT

Before analysis, specify
the claim you are trying to earn.

TargetWhat exactly is being predicted or explained?
UnitWhat is one observation?
EvidenceWhich variables are admissible?
Failure checksLeakage, missingness, subgroup error.
Prompt the agent to expose assumptions before it produces results.

我们给 agent 的 prompt 不能只是“跑机器学习并解释”。一个 practical research contract 至少要声明 target、unit of analysis、admissible variables 和 failure checks。还要告诉 agent：先列 assumptions 和 analysis plan，再运行。这样 agent 的输出不是一张神秘结果表，而是一个可以被研究者审查的 analytical proposal。

THE WORKING LOOP · 02

Use three models to ask three
different empirical questions.

OLSIs there a stable average relationship?interpretable baseline · linear specification
TREEAre there thresholds or conditional rules?visible partitions · unstable boundaries
RANDOM FORESTDoes complex structure generalize?out-of-sample prediction · weaker interpretation
Do not choose the “winner” before deciding what question each model is allowed to answer.

这里把 OLS、Decision Tree 和 Random Forest 放回一个实际分析任务。OLS 先问平均关系是否稳定；Tree 问是否存在 threshold 和 conditional rule；RF 问复杂结构是否能改善 unseen cases 的 prediction。先不要宣布哪个 model 最强。三个模型其实是在问三个不同的问题，所以 comparison 的重点是：每个模型让我们看到什么，允许我们说什么，又不能说什么。

THE RESEARCHER SAYS NO
Agent contribution

Generate candidate interpretations.

Researcher contribution

Reject an inference that exceeds the design.

TWO MOMENTS OF REFUSAL

The collaboration becomes research
when the researcher refuses the easy story.

AGENT SUGGESTS“The important variable measures cultural identity.”Researcher: it may instead capture access, resources, or institutional reach.REJECT · identity is not identified
AGENT SUGGESTS“Random Forest is best, so use it as the main explanation.”Researcher: better prediction does not establish a better mechanism.REJECT · prediction ≠ theory
Refusal is not resistance to AI. It is the moment where epistemic responsibility becomes visible.

这一页必须明确展示 researcher 说“不”。第一个拒绝是：agent 看到某个变量重要，就把它命名为 cultural identity。研究者要问，这个变量是否也只是资源、渠道或制度触达的 proxy。第二个拒绝是：RF test error 更低，所以 agent 建议把 RF 当作主解释模型。研究者要说，预测优势不能自动转成机制优势。拒绝不是反对 AI，而是把 interpretation 拉回 design 能够承担的范围。

EVIDENCE CHECK
Agent produces

tables, plots, diagnostics, candidate explanations

Researcher checks

meaning, design validity, and claim ceiling

THE OUTPUT IS A REVIEW PACKET

A result is not yet an inference.
Build an evidence packet.

DATAsplit + missingness + leakage
MODELspecification + hyperparameters
RESULTtest error + subgroup error
INTERPRETATIONsupported / uncertain / prohibited
The agent can assemble the packet. The researcher decides whether the packet warrants the claim.

实际工作中，agent 不应该只返回“RF 表现最好”。它应该生成 evidence packet：数据怎么 split，有没有 leakage，模型的 specification 和 hyperparameters，test error 和 subgroup error，以及 interpretation 分成 supported、uncertain 和 prohibited。这个 packet 让我们把 prediction、association 和 causal interpretation 分开。agent 可以组装证据，但 researcher 决定证据是否足够让一个 claim 成立。

THE WORKING LOOP · 03

Make the agent attack
the explanation, not just polish it.

CLAIMresponse time matters
→
ATTACKproxy? leakage? subgroup?
→
REVISEprediction, not causality
→
BOUNDwhat remains unknown?
Ask the agent for the strongest alternative explanation before asking it to write the paragraph.

这一页是实际合作中最容易被忽视的环节。agent 不应该只帮我们把结果写得更像论文，而应该攻击解释：这个变量是不是 proxy？是不是 leakage？是不是只在某个 subgroup 中成立？有没有一个竞争性机制也能产生同样的 pattern？我们先让 agent 进行 adversarial critique，再决定是接受、修改还是降低 claim。写作应该是这个过程的最后一步，不是第一步。

THE HUMAN DECISION
Not “accept or reject AI”

Decide what kind of knowledge the evidence supports.

Claim ceiling

Prediction ≠ explanation ≠ causality.

THE LAST PRACTICAL STEP

Choose the claim before
you choose the story.

LEVEL 1PredictionWill the model generalize to new cases?
LEVEL 2AssociationWhich variables co-vary with the outcome?
LEVEL 3MechanismWhat process could plausibly generate it?
LEVEL 4CausalityWhat design identifies an effect?
Most AI-assisted analysis stops below the level of causal identification.

最后一个 practical judgment 是 claim ceiling。我们先决定 evidence 允许我们说到哪一层，再决定怎样写故事。预测能不能泛化，是一层；变量之间的 association 是一层；机制解释需要更多理论和证据；causality 需要识别设计。很多 AI-assisted analysis 把 model importance 写成 mechanism，把 prediction 写成 explanation，再把 explanation 写成 causality。研究者必须在这里踩刹车。

到这里，学生已经看到一个 practical loop：agent 提议，researcher 判断；analysis 产生 evidence packet；agent 攻击 explanation；researcher 设置 claim ceiling；过去的决定进入下一轮。现在才适合进入理论语言。我们可以把“agent 提议、researcher 判断”抽象成 distributed epistemic labor with asymmetric authority；把“过去决定进入下一轮”抽象成 temporal interdependence 和 organizational memory。理论不是额外加上去的，而是对实际 workflow 的抽象。

THE ZOOM-OUT MOVE
Do not ask first

What can the agent do?

Ask instead

What does the arrangement make persistent, distributed, contestable, and accountable?

FROM TOOL USE TO ORGANIZATIONAL FORM

The object of analysis is not the agent.
It is the research arrangement.

Persistentwhat survives the current interaction
Distributedwhose epistemic labor is involved
Contestablewhere alternatives and dissent enter
Accountablewho authorizes the claim
Organization Science question: how are work, authority, memory, and control reconfigured?

这里要完成从工具视角到组织视角的转化。工具视角会问 agent 能不能搜索、写代码、总结或跑模型。Organization Science 更关心：研究活动如何分工，哪些状态被保存，谁拥有解释权，哪里可以提出异议，以及谁对最终的知识主张负责。这个转向与 Brown 和 Duguid 对 situated practice 的讨论相连：实际工作和学习并不等于组织文件里对工作的正式描述。

THE UNIT OF SCIENTIFIC PRODUCTION

Task → paper → inquiry loop.

01Tasksearch · code · estimate · write
02Papercompressed and stabilized knowledge product
03Inquiry loopconjecture → evidence → anomaly → critique → revision
The paper is a temporary cross-section of a longer inquiry loop.

传统学术生产把 paper 当成主要单位。可是产生 paper 的过程里，失败分析、被放弃的机制、竞争性解释和测量变化，通常都会被压缩掉。agent collaboration 让我们有可能把 inquiry loop 本身作为一个持续的 research object。不是说 paper 消失了，而是说 paper 变成一个阶段性的 stabilization。这个想法和 Brown、Duguid 对工作实践的观察很接近：真正的 learning and innovation 往往发生在正式描述之外。

DIVISION OF LABOR
Ordinary division

Who collects, codes, writes, and submits?

Epistemic division

Who formulates, challenges, interprets, and authorizes?

FROM DIVISION OF LABOR TO DIVISION OF EPISTEMIC LABOR

Work can be distributed.
Authority cannot simply be equalized.

AGENT CAN CONTRIBUTEsearch · recombine · diagnose · challenge · remember
HUMAN MUST AUTHORIZEproblem value · mechanism · evidentiary sufficiency · public claim
Distributed epistemic work ≠ distributed epistemic authority.

这不是说 human 总是比 agent 聪明，而是说两者承担的 epistemic role 不同。agent 可以进行大量搜索、重组、分析和批评，但不能自动决定一个问题为什么有社会理论意义，也不能自动承担发表一个解释的责任。Hutchins 的 distributed cognition 让我们看到，认知活动可以分布在行动者、工具和表征之间；但 distributed cognition 不意味着 agency 和 accountability 自动对称。

“Assistant”这个词暗示问题已经存在，agent 只是执行。但在长期合作里，agent 会参与把模糊直觉变成 puzzle，把 puzzle 变成 mechanism，把结果重新变成下一轮的问题。它不决定最终的问题价值，但它会影响哪些区分变得可见，哪些解释变得可说，哪些方向值得继续。这就是从 instrumental view 转向 constitutive view。

RECURSIVE COUPLING

Research is not a pipeline.
It is a feedback architecture.

theory

anomaly

Each round can reorganize the next round’s question, measure, model, and claim.

Methods 课常把研究画成 theory 到 hypothesis、data、analysis、conclusion 的单向链条。但真实研究不是这样，尤其不是我们和 agent 的长期合作。异常会改变 mechanism，mechanism 会改变 measurement，measurement 会改变 model，model 又会改变我们对异常的理解。这可以用 Crossan、Lane 和 White 的 organizational learning framework 来理解：intuition、interpretation、integration 和 institutionalization 之间存在 feed-forward 与 feedback。

持久记忆不是简单的便利功能，而是改变了研究的时间结构。过去被拒绝的解释、失败的 operationalization、leakage warning 和 claim ceiling，都可以进入下一轮设计。这给 inquiry loop 带来 continuity。但 continuity 也会形成 path dependence：早期一个错误的测量可能被反复复用。Nonaka 讲 organizational knowledge creation 时强调，知识不是静态存储，而是在 articulation、amplification、connection 和 reinterpretation 中被创造。agent memory 也必须如此治理。

Under what interaction architectures does AI produce exploration rather than accelerated exploitation? (March, 1991)

March 的 exploration/exploitation 不是一个简单的“创新 versus 保守”标签。exploration 是在不确定回报下进行 search、variation 和 experimentation；exploitation 是对已有 competence 的 refinement。agent 可以大幅降低探索多个机制和多个 model specification 的成本，但它也可能把陌生问题迅速翻译成熟悉的理论语言。因此问题不是 AI 是否 creative，而是研究组织的 interaction architecture 是否允许 divergence，还是奖励 premature closure。

我们通常说 AI 的价值是减少 friction。但科学不是越顺滑越好。有些 friction 是无意义的：文件找不到、代码跑不起来、重复格式化。这些可以自动化。另一些 friction 是知识生产的机制：替代解释、measurement challenge、claim ceiling 和 negative case。好的 agent collaboration 不会把第二类摩擦消灭，而是把它提前、持续、可审计地放进研究过程里。

这里不要说一句空泛的“AI 不会取代人类”。更精确的说法是：AI shifts the locus of scholarly expertise。研究者不必手工执行每一个 operation，但必须更清楚地设计 inquiry architecture，管理 disagreement，判断 evidence 是否真的识别 claim，并对 public interpretation 负责。社会科学家的角色部分转向 architect、curator 和 guarantor。

PROPOSED THEORETICAL CONTRIBUTION

Three mechanisms of AI-enabled science.

01Recursive availabilitypast conjectures, failures, and boundaries remain available to the next move
02Asymmetric judgmentepistemic work is distributed, but authority and accountability are not
03Institutionalized frictioncritique and divergence become workflow infrastructure
More specific than “AI helps science”; more general than one product.

这三个 mechanism 可以组织未来 Special Issue 文章的理论部分。第一，recursive availability：过去的 conjecture、failure 和 boundary 可以被下一轮分析调用。第二，distributed but asymmetric judgment：epistemic work 可以分布，但 authority 和 accountability 不能平均分配。第三，institutionalized epistemic friction：critique、divergence 和 limitation 不再只是外部 peer review 的阶段，而成为 workflow 的内部设施。

BOUNDARY CONDITIONS
Recursive does not mean valid.

A loop can reproduce its own errors.

THE LOOP IS NOT AUTOMATICALLY SCIENTIFIC

When the loop fails, it produces more output without expanding inquiry.

generation mistaken for explanation
prediction mistaken for causality
memory becomes unreviewed authority
plurality becomes interpretive relativism
critique is performed but cannot change the claim
The question is not whether the agent participated, but whether the arrangement changed the defensible scope of inquiry.

我们不是来庆祝这个 loop 的。recursive system 也可以 recursively reproduce its own errors。生成不等于解释，prediction 不等于 causality，persistent memory 可能变成 unreviewed authority，model plurality 也可能变成“什么解释都可以”。所以这篇文章必须同时是 boundary-setting contribution：AI 参与了，并不代表 research contribution 自动成立。

TAKEAWAY

The question is not whether an agent
can do research tasks.

The question is whether a human–agent arrangement can sustain forms of inquiry that conventional research organizations suppress.

EXPLOREprolonged searchuncertain ideas can survive longer

REMEMBERpreserved failurethe loop carries its history forward
AI-enabled science is not simply faster science. It is science reorganized around a different unit of inquiry.

最后留下三句话。第一，AI-enabled science 不是简单地把旧科学做得更快。第二，它可能把 scientific production 的 unit 从 completed paper 推向 recursively organized inquiry loop。第三，社会科学家的责任不是消失，而是转向设计这个 loop、治理其中的 disagreement，并对 loop 最终产生的 claim 负责。Part 1 展示 collaboration；Part 2 把它理论化为一种 organization of science。
