# Lesson 04 · The Organization of Science

HTML slide deck for Pre/L4 Part 2.

This 26-slide deck is split into two halves. Part 1 is a practical research collaboration: puzzle, mechanism, analysis contract, OLS / Tree / RF comparison, evidence packet, adversarial critique, researcher refusal, and claim ceiling. Part 2 lifts that workflow into Organization Science language: epistemic labor, recursive coupling, research memory, exploration/exploitation, epistemic friction, and the AI-enabled inquiry loop.

Open `index.html` in a browser. Use `←` / `→` to navigate, `O` for overview, `T` to cycle themes, `F` for fullscreen, and `S` for presenter mode. Speaker notes are embedded in each slide inside `aside.notes`.

The content source and in-text citations are in [`lesson_text.md`](lesson_text.md).
