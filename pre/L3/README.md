# Lesson 03 · Four Theories of an Agent

HTML slide deck for the third AI / ML course lesson.

## Focus

This version compares OpenClaw, Hermes Agent, OpenAI Codex, and Claude Code through their engineering mechanisms rather than a generic capability list. It also introduces Skills and MCP as shared infrastructure concepts:

- Hermes: experience becomes reusable procedure through memory, skills, proposals, and review.
- OpenClaw: the agent becomes personal infrastructure through a gateway, channels, nodes, workspace state, and governed self-learning.
- Codex: work becomes parallel, isolated, and reviewable through tasks, sandboxes, worktrees, skills, and evidence.
- Claude Code: the agent inhabits the repository through hierarchical `CLAUDE.md`, rules, hooks, subagents, and permissions.
- Skill: reusable procedural memory — how to work.
- MCP: a Host–Client–Server protocol exposing tools, resources, and prompts — what to reach.
- Plugin / package: a distribution layer bundling skills, apps, connections, and permissions.
