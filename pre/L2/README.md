# Lesson 02 · From Learning Algorithms to Learning Systems

HTML slide deck for the second ML / AI course lesson.

## Focus

The deck compares the classical textbook grammar of machine learning with contemporary engineering practice: foundation models, learned representations, PEFT/LoRA, multi-objective evaluation, distribution shift, trace-level observability, and production feedback loops.

## Open

Open `index.html` in a browser. Use `←` / `→` to navigate, `O` for overview, `T` to cycle themes, `F` for fullscreen, and `S` for presenter mode.

## Source notes

The deck uses original SVG/CSS teaching diagrams and links to first-party learning references from Google ML Crash Course, TensorFlow Embedding Projector, Hugging Face PEFT, and MLflow tracing.
